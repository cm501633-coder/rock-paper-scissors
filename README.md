# Rock Paper Scissors

A simple Python game where the user plays rock, paper, or scissors against the computer.

## Run it

```bash
python rock_paper_scissors.py
```

## Gameplay

- Enter `rock`, `paper`, or `scissors`
- The computer chooses randomly
- The script prints the outcome and declares the winner

## Project

Rock–Paper–Scissors — a simple command-line game that lets a player play rock, paper, scissors against the computer.

Key features
- Player vs computer gameplay
- Input validation and replay option
- Score tracking for the session
